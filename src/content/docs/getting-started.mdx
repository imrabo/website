## Before you begin

Start by identifying which ImRabo component you intend to use. The website, CLI package and any future platform applications may have different setup requirements.

## Choose a starting point

- **Product overview:** review the [features page](/web/features/).
- **Platform availability:** review [platforms](/web/platforms/).
- **CLI package:** consult the [published npm package](https://www.npmjs.com/package/@imrabo/cli) and its current README.
- **Source code:** browse the [ImRabo GitHub organization](https://github.com/imrabo).

## Check compatibility

Before installing a package, verify its current version, Node.js requirements, supported operating systems and configuration instructions in the package documentation.

## Important

This guide does not imply that every planned ImRabo capability is currently released. Treat the published package and repository documentation as authoritative for implementation details.
