## Install the CLI

The ImRabo CLI package is published at [npm](https://www.npmjs.com/package/@imrabo/cli). Check the package page for the latest installation command and supported runtime version before installing.

```bash
npm view @imrabo/cli version
npm view @imrabo/cli engines
```

If the package metadata confirms a global CLI installation, use the command documented by that package. Do not assume command names or runtime requirements from this website.

## Verify the installation

After installation, run the version or help command documented in the package README.

## Troubleshooting

- Confirm Node.js meets the package's declared engine range.
- Confirm the package manager completed without dependency errors.
- Review the package README and issue tracker for known problems.
- Include the CLI version and operating system when reporting a reproducible issue.

## Security

Install packages from the official npm listing and review package ownership, release history and repository links before using them in production.
